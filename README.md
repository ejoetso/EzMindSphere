# EzMindSphere

EzMindSphere is a real-time educational mind-mapping, polling, Q&A, and collaborative classroom platform for educators and students.

Copyright © 2026 Ejoe Tso. Free for eligible educational institutions under the [Educational Institution License](LICENSE.md). Activation is required.

## Quick start

```bash
git clone https://github.com/ejoetso/EzMindSphere.git
cd EzMindSphere
cp .env.example .env
docker compose up -d --build
```

Open `http://localhost:3000`, activate the platform, and use the default educator login:

- Username: `ezmindsphere`
- Password: `admin@123`

Change default credentials before production use.
